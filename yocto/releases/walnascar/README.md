# Walnascar

Yocto Project Walnascar is the `5.2` regular release series. The upstream archive's release notes
are dated 2025-05-07; it lists `5.2.4` as the latest point release on 2025-10-14.

This directory contains the repository's `5.2.0` through `5.2.4` manifests. Each YAML file pins
the upstream layers and commits used for reproducible Walnascar builds.

Browse the published files at
<https://downloads.yoctoproject.org/releases/yocto/yocto-5.2/>.

See the [Yocto releases index](../README.md) for the complete release list. The shared repository
definitions are in [`../../yocto.yaml`](../../yocto.yaml).
