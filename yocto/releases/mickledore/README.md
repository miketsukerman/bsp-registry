# Mickledore

Yocto Project Mickledore is the `4.2` regular release series. The upstream archive's release
notes are dated 2023-05-03; it lists `4.2.4` as the latest point release on 2023-12-08.

This directory contains the repository's `4.2.0` through `4.2.4` manifests. Each YAML file pins
the upstream layers and commits used for reproducible Mickledore builds.

Browse the published files at
<https://downloads.yoctoproject.org/releases/yocto/yocto-4.2/>.

See the [Yocto releases index](../README.md) for the complete release list. The shared repository
definitions are in [`../../yocto.yaml`](../../yocto.yaml).
