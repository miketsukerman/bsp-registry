# Whinlatter

Yocto Project Whinlatter is the `5.3` regular release series. The upstream archive's release
notes are dated 2025-12-16; it lists `5.3.4` as the latest point release on 2026-05-12.

This directory contains the repository's `5.3.0` through `5.3.4` manifests. Each YAML file pins
the upstream layers and commits used for reproducible Whinlatter builds.

Browse the published files at
<https://downloads.yoctoproject.org/releases/yocto/yocto-5.3/>.

See the [Yocto releases index](../README.md) for the complete release list. The shared repository
definitions are in [`../../yocto.yaml`](../../yocto.yaml).
