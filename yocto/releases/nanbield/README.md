# Nanbield

Yocto Project Nanbield is the `4.3` regular release series. The upstream archive's release notes
are dated 2023-11-09; it lists `4.3.4` as the latest point release on 2024-04-09.

This directory contains the repository's `4.3.0` through `4.3.4` manifests. Each YAML file pins
the upstream layers and commits used for reproducible Nanbield builds.

Browse the published files at
<https://downloads.yoctoproject.org/releases/yocto/yocto-4.3/>.

See the [Yocto releases index](../README.md) for the complete release list. The shared repository
definitions are in [`../../yocto.yaml`](../../yocto.yaml).
