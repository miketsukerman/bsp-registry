# Wrynose

Yocto Project Wrynose is the `6.0` regular release series. The upstream archive's release notes
are dated 2026-05-12; it lists `6.0.2` as the latest point release on 2026-07-15.

This directory contains the repository's `6.0.0` through `6.0.2` manifests. Each YAML file pins
the upstream layers and commits used for reproducible Wrynose builds.

Browse the published files at
<https://downloads.yoctoproject.org/releases/yocto/yocto-6.0/>.

See the [Yocto releases index](../README.md) for the complete release list. The shared repository
definitions are in [`../../yocto.yaml`](../../yocto.yaml).
