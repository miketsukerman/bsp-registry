# Scarthgap

Yocto Project Scarthgap is the `5.0` Long Term Support (LTS) series. The upstream archive's
release notes are dated 2024-04-30; it lists `5.0.19` as the latest point release on 2026-07-21.

This directory contains the repository's `5.0.0` through `5.0.19` manifests. Each YAML file pins
the upstream layers and commits used for reproducible Scarthgap builds.

Browse the published files at
<https://downloads.yoctoproject.org/releases/yocto/yocto-5.0/>.

See the [Yocto releases index](../README.md) for the complete release list. The shared repository
definitions are in [`../../yocto.yaml`](../../yocto.yaml).
