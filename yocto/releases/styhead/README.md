# Styhead

Yocto Project Styhead is the `5.1` regular release series. The upstream archive's release notes
are dated 2024-10-16; it lists `5.1.4` as the latest point release on 2025-04-01.

This directory contains the repository's `5.1.0` through `5.1.4` manifests. Each YAML file pins
the upstream layers and commits used for reproducible Styhead builds.

Browse the published files at
<https://downloads.yoctoproject.org/releases/yocto/yocto-5.1/>.

See the [Yocto releases index](../README.md) for the complete release list. The shared repository
definitions are in [`../../yocto.yaml`](../../yocto.yaml).
