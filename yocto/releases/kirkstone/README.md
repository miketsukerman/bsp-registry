# Kirkstone

Yocto Project Kirkstone is the `4.0` Long Term Support (LTS) series. The upstream archive's
release notes are dated 2022-04-26; it lists `4.0.35` as the latest point release on 2026-04-29.

This directory contains the repository's `4.0.0` through `4.0.35` manifests. Each YAML file pins
the upstream layers and commits used for reproducible Kirkstone builds.

Browse the published files at
<https://downloads.yoctoproject.org/releases/yocto/yocto-4.0/>.

See the [Yocto releases index](../README.md) for the complete release list. The shared repository
definitions are in [`../../yocto.yaml`](../../yocto.yaml).
